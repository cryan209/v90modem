# The Modem Lab

Interactive JavaScript FSK, real WebAssembly V.22/V.22bis/V.23/Bell 212A/
V.32/V.32bis/V.34/V.90/V.91/V.92 calls, and
x2/K56flex downstream PCM payload demos with independent decoders.

Includes V.92 full/Quick Connect comparisons, adjustable analogue V.32/V.34
line impairments, codeword-preserving delay, and measured transfer statistics.
The Reliability test compares repeated fresh V.34/V.90/V.92 calls with 30 or
60 seconds of independently verified traffic and exportable results.

See [browser demo documentation](../../docs/browser_modem_demo.md) for running,
rebuilding, verification, signal paths, and limitations.
