# Environment variables

Generated by `tools/env_knobs_inventory.py`; regenerate it rather than editing the
tables. 668 names are read: 313 on the live call path (`SRCS` and SpanDSP) and 355 only
by offline tools and tests.

The supported interface is the AT command set on the PTY (`AT+MS`, `AT+ES`, `AT+DS`, ...).
Environment variables are, in decreasing order of legitimacy:

- **settings**: the short list below;
- **diagnostics**: dumps, traces and logs, safe to leave in;
- **test hooks**: provoke an event (`*_AFTER_MS`, `*_FORCE*`) for a harness;
- **switches**: everything else. Nearly all of these either restore the behaviour
  before a measured fix (`=0 disables`) or enable an experiment that was measured
  and left off. They are the removal backlog: hard-code the default that the
  measurement chose and delete the other branch.

`refs` says where a name is used outside the code that reads it: `c` code that
sets it for a callee, `t` a test
or the makefile, `s` a script, `d` a current doc, `h` `docs/project_history.md`
(where the measurement behind most switches is recorded). A switch with no `c`,
`t`, `s` or `d` is the first thing to remove.
