# Documentation index

One note per topic. Read the relevant note before changing a phase, and record
new findings in it, not in `CLAUDE.md`/`AGENTS.md`. Dated notes
(`*_2026MMDD.md`) are a record of one rig session and are not kept current;
the undated note on the same topic is. The project-wide lab notebook is
[project_history.md](project_history.md).

Where to start:

- building, making your first call, attaching an application, and troubleshooting:
  [user guide](usage.md);
- what works and what is unqualified: [the top-level readme](../readme.md) and
  [current open-work backlog and historical gap analysis](gap_analysis_2026-10.md);
- running a live call against hardware: [v90_hardware_interop.md](v90_hardware_interop.md)
  and [rig/README.md](../rig/README.md);
- configuration: the AT commands ([at_commands.md](at_commands.md),
  [at_stored_profiles.md](at_stored_profiles.md)); environment variables are
  inventoried and classified in [env_knobs.md](env_knobs.md) (generated, do not edit);
- tools and make targets: [tools/README.md](../tools/README.md);
- where captures and fixtures belong: [artifact_storage.md](artifact_storage.md).

## Reference material

The PDFs, `.HEX`/`.XMD`/`.xmf` files and the `*adsp2100*`/`*_hardware`
directories here are vendor datasheets, application notes and firmware images
(ADSP-21xx manuals and EE notes, the AD1847 codec, a Silicon Labs DAA, the
Courier `SV25.XMD` image) used by the firmware and DAA work. ITU
Recommendations are in `ITU Docs/`.
