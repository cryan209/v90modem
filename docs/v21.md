# V.21 300-bit/s mode

`AT+MS=V21,0,300,300` selects fixed V.21; `--mode v21` sets the power-on offer.
The vendored SpanDSP FSK presets implement V.21 §§2–3: 300 bit/s, caller
channel 1 (980/1180 Hz), answerer channel 2 (1650/1850 Hz), high frequency
for zero. Channel assignment follows §7(a), asynchronous bits follow §4.

This fixed-mode path starts FSK when SIP media connects and reports CONNECT
300 after the opposite channel's carrier is detected. It has no V.8 or
V.25 automatic answer-tone negotiation. Both ends must select V.21 out of
band. Bell 103 remains unavailable; its tones are different.

The GUI local echo profile uses buffered V.14 framing. The ordinary engine
retains the configured link policy; use `AT+ES=0,0,0` for asynchronous data.
FSK transmit and receive state is released on disconnect and recreated per
call. Idle transmission is mark, and a connected carrier loss hangs up.
No new sample buffering or conversion is added.

The complete engine-pair regression and local SIP GUI echo both return binary
payloads including every byte value. The GUI test collects output as it arrives:
its bounded 256-chunk display can otherwise discard the beginning of a long,
slow stream before the whole pattern finishes. No extra storage is required.
